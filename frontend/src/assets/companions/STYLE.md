# 伴讀角色繪製規格

伴讀角色是「尤提姆」式的小動物夥伴：只畫動物本身（連同牠身上的小配件），不畫人物、箱子或場景；使用乾淨的暖象牙白淺色背景。
風格參考《1999：重返未來》星尤提姆影集裡**箱子中的動物**，而不是 3D 渲染或寫實毛皮插畫。

## 整體感覺

- 2D 手繪的遊戲角色插畫，像是繪本裡的動物被畫成收藏卡上的一格。
- 安靜、帶一點懷舊與故事感；可愛來自小配件和神情，不是靠大頭大眼的 Q 版比例。
- 一眼看得出是「平面插畫」：沒有 3D 體積感、沒有景深模糊、沒有塑膠或絨毛質感。

## 造型與比例

- 動物比例接近真實但稍微簡化、拉長或圓潤：頭略大、四肢細、輪廓乾淨，不做 Q 版二頭身。
- 大塊、好辨認的剪影；在 128px 小尺寸下仍看得出是什麼動物、身上戴了什麼。
- 每隻角色只保留一個有辨識度的小配件（圍巾、眼鏡或睡帽），和角色個性呼應。
- 姿勢自然安定（坐、站、趴），3/4 側面，稍微朝向畫面左方。

## 線條

- 有清楚的描線，顏色是深褐或深色系的「色線」，不是純黑。
- 線寬中等且均勻，外輪廓略粗、內部細節略細；線條乾淨俐落，不要素描感的重複線。
- 毛髮只在輪廓與關鍵處用幾道鋸齒狀的線或尖角表示（臉頰、胸口、耳內、尾巴末端），**不畫一根一根的毛**。

## 上色

- 平塗為主的賽璐璐上色：每個色塊一個底色 + 1–2 階硬邊陰影，陰影形狀簡潔。
- 可以有很少量的柔和漸層（例如腹部、耳內），但不做噴槍式立體打光。
- 高光很少：眼睛一顆小亮點、金屬或眼鏡一道細亮線即可。
- 色調偏低彩度、帶灰的溫暖色（栗褐、奶油白、灰藍、墨綠、酒紅），避免鮮豔的純色與螢光色。
- 以描邊與色塊讓角色從背景跳出來，不加邊緣光或發光特效。

## 眼睛與表情

- 眼睛簡單：深色瞳孔 + 一顆小高光，有細細的眼線；不做閃亮的大眼或多層反光。
- 表情克制，靠眼神、耳朵角度、嘴角傳達個性（沉穩、機靈、睏倦）。

## 不要

- 3D 渲染、立體絨毛、寫實毛皮紋理、次表面散射的柔光。
- 場景背景、地板、投影、箱子、檯燈、邊框、文字、浮水印。
- 人物角色。
- 過度可愛的 Q 版比例、大頭貼式的誇張表情。

## 輸出

- 單一角色的正方形全身 PNG，暖象牙白淺色背景；角色置中，約占畫面 80–85%，耳朵、腳與尾巴完整入鏡。
- 本次原始輸出為 1254×1254 PNG，保存在 `output/imagegen/companions/{fox,otter,owl}.png`（相對於專案根目錄）。
- 使用內建 image_gen 生成；完整提示詞記錄在 `output/imagegen/companions/prompts.json`。
- 應用程式使用同名 512×512 WebP：`cwebp -q 90 -resize 512 512 in.png -o <id>.webp`。
