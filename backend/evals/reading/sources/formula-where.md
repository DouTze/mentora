# 均方誤差

迴歸模型最常用的損失函數是均方誤差，它的定義為：

$$
\mathrm{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

其中 $n$ 是樣本數，$y_i$ 是第 $i$ 筆資料的真實值，$\hat{y}_i$ 是模型的預測值。由於誤差先平方再平均，較大的誤差會被放大，因此均方誤差對離群值特別敏感。

另一個常見的選擇是平均絕對誤差。它直接平均誤差的絕對值，不做平方，所以受離群值影響較小，但在零點不可微。

當我們把預測值寫成線性模型 $\hat{y}_i = \mathbf{w}^\top \mathbf{x}_i + b$ 時，最小化均方誤差就等於求解最小平方問題；若 $\mathbf{X}^\top \mathbf{X}$ 可逆，解為 $\mathbf{w}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$。
