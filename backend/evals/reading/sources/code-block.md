# 串列推導式

Python 的串列推導式可以在一行內由既有的序列建立新串列，並可加上條件來過濾元素。下面的程式把 0 到 9 之中的偶數平方後收集起來。

```python
squares = [n * n for n in range(10) if n % 2 == 0]

# 等價的迴圈寫法
result = []
for n in range(10):
    if n % 2 == 0:
        result.append(n * n)
```

兩種寫法都得到 `[0, 4, 16, 36, 64]`。推導式的條件 `if n % 2 == 0` 寫在最後，只有條件成立的元素才會被平方並放進結果；這和迴圈版本中 `if` 包住 `append` 的效果完全相同。
