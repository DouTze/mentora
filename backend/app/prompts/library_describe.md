## 要求
- description：用繁體中文寫一句話（最多 60 字），說明這是什麼：主題、類型（教科書、講義、論文、筆記…），看得出來時再加上作者或適合的程度。只寫上面的資料看得出來的事，看不出來的不要猜。
- alias：一個簡短、好記、能和其他書區分的稱呼（2–16 個字），讓學習者或導師可以用它指稱這本書，例如作者加主題、書的常見簡稱。不要直接重複完整書名；書名本身已經很短時，可以用常見的簡稱或中文譯名。
- 檔名裡的編號、日期、版次、下載站名稱等雜訊不要寫進 description 或 alias。
